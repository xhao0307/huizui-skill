# 首轮公开材料研究：从接话方式到案例卡

研究日期：2026-11-26。此轮改动以 `3de7e84` 版本为基线。

## 做了什么，没测到什么

此前版本主要由通用要求和自行编写的示例组成。本轮查看公开贴吧讨论及年度幽默精选的文本整理，抽取可迁移的接话结构，加入 **7 张机制卡、14 张原创对照案例卡**，并要求技能在生成前阅读、匹配和检查反例。

这是**材料启发的上下文与案例增强**：没有训练模型、修改权重、制作辱骂原文数据库，也没有独立盲测结果证明新版优于同模型的原生提示词。是否更有用，需要按 [比较方案](../../evals/ab-protocol.md) 另行检验；不能拿示例好笑、字数变短或静态校验通过代替效果证据。

## 材料范围

| 代号 | 材料性质 | 实际查看范围 | 用途与限制 |
| --- | --- | --- | --- |
| A1 | 公开的骂人语句挑战及跟帖 | 页首可见的两个挑战与部分楼中楼 | 观察接住原词、改变方向的回复；未读取全部回复，不证明回复者获胜 |
| A2 | 公开的骂人语录讨论 | 前部可见楼层与回复 | 大部分内容淘汰；仅一处围绕既成结果的回复用于结构观察 |
| A3 | 作品被否定后的求助讨论 | 公开可见的作品片段及部分评论 | 作为反例：难听的评论可能仍有具体内容，不能一律按恶意处理 |
| A4 | 一届年度幽默精选帖 | 评选说明及首个可见条目 | 只了解筛选方式；首个条目未采用，未读取整届精选 |
| B | 另一公开仓库整理的多年年度幽默精选 JSON | 共 1,361 个记录；两组关键词筛出 97 个候选记录并逐一查看 | 其中 13 个条目用于机制对照；属于二手转录，未逐条核验原帖与作者 |

两个精选来源不是同一届材料，不合并宣称为某一届完整样本。JSON 记录可能是多个段子的拼接或说明文字，**记录数不等于独立原帖数**。其作者字段也可能指整理者，不能当作原创归属。本轮没有使用该仓库其他大规模标题集。


再按以下词组检索，排除第一组已经命中的记录，得到另外 66 个：


这只是偏向争执、评价与说理情境的一轮定向抽样，不代表贴吧全貌，也不代表“贴吧最佳 97 条”。剩余记录未逐条评审。13 个条目的用途是检查结构能否说清楚，不能称为 13 条实战有效的回击。

## 怎么取舍

保留结构观察时，至少满足：

1. 能解释落点：用了哪个词、反差或转折，为什么与前文有关。
2. 能迁移：换成全新虚构场景后仍然成立，不靠原人物、热梗身份或罕见事件。
3. 能指出失效条件：背景一改，知道什么时候不能用。
4. 在短句里完成：不靠补一段解释才能看懂。

淘汰的材料包括无原帖支持的“神回复”清单、疑似 AI 二次拼写的榜单、重复辱骂、单纯猎奇、亲属与性暴力攻击、歧视性笑料，以及只靠人名谐音成立的内容。实际线程中，大量内容都不适合迁移；不以热度或回复数量代替质量判断。

## 从材料到技能的对应关系

| 机制 | 材料启发 | 本项目增加的约束 |
| --- | --- | --- |
| P1 借词回弹 | A1：复用原词并改变方向 | 必须回到已知行为，不弹回无依据的人身指控 |
| P2 接半句再转弯 | A1 与 B：接住说辞后揭示落差 | 不把讽刺角色当作对方真实动机 |
| P3 用事实截断 | A2：用既成结果结束一轮 | 区分发出、收到、读过，以及部分贡献和全部功劳 |
| P4 拿同一把尺子量 | B：规则回送、尺度变化 | 先确认同一说话者、同类行为与相近条件 |
| P5 把空话放到眼前 | B：字面解释和句尾语义转折 | 不为谐音牺牲针对性，不把回击写成谜语 |
| P6 顺着往后走一步 | B：规则多走一步、跳出伪选择 | 真实存在的二选一或具体追问不算封闭话术 |
| P7 把名头拆回动作 | B：成因与功劳、标签与能力的错位 | 不凭没看到工作就断言没有工作 |

“不混淆说话者”“承认用户的具体错误”“不保存个人资料”等是项目原有原则及本轮编辑判断，并非从这些帖子推导出的研究结论。案例卡的反例也是本项目创作，不冒充原帖回复。

## 来源与隐私

仓库只保留机制、统计、处理方法和原创虚构案例。不收录原句、截图、个人主页、昵称、群名或足以复原真实冲突的细节，也不把第三方数据改标为 MIT 后重新分发。

来源 URL、可见范围与条目索引另存于仓库外的维护记录；该记录不包含原文、用户名或作者字段。**当前公开仓库没有完整的逐条溯源链接，因此读者不能仅凭本仓库完全复核材料筛选。** 本页是范围透明的编辑记录，不是可下载的训练集或完整公开研究数据。

第三方材料的许可不因本仓库采用 MIT 而改变。若以后公开更多研究资料，应先明确授权与隐私处理范围。
