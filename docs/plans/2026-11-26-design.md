# 回嘴第一版设计

## 需求

创建可发布到 GitHub 的中文回击技能。参考贴吧短句和讽刺，一次给多种回复让使用者选择。项目只使用原创虚构场景，不含真实个人信息、原始聊天或可追溯细节。

## 方案选择

采用“对话输入 → 核对语境 → 五种策略成稿”的轻量技能。相比固定金句库，它根据当前事实生成回复；相比人物画像和陪练机器人，它不需要建立人物档案或收集额外资料。

## 组成

- `skills/huizui/SKILL.md`：请求识别、事实核对、语气与默认输出。
- `skills/huizui/references/playbook.md`：表达手法及适用条件。
- `skills/huizui/references/examples.md`：原创虚构交付示例。
- `evals/cases.md`：事实归属、输出区别、上下文不足、隐私与外部动作检查。
- `README.md` 与 `CONTRIBUTING.md`：使用、安装与贡献规则。

不依赖联网、外部账户或运行脚本。技能只生成草稿，没有发布、发送消息或聊天采集模块。

## 限制

效果取决于模型和上下文，不承诺争执结果。结构校验与人工检查不等于多模型、多客户端实测。后续根据虚构用例中的真实失败改进。
