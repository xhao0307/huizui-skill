# 表达手法

按对话选一两种手法，不把回复写成固定句式。以下均为虚构片段。

## 把规则推到它自己身上

适合双重标准。指出同一规则如何被选择性使用，不捏造对方做过什么。

- 情境：对方拒绝回答问题，却要求自己提出的每个问题都必须得到回答。
- 回法：你这问答规则还挺方便，提问归你，回答全归别人。
- 不适合：双方权限、责任本来就不同，不能只因为不同就叫双标。

## 让结论回到证据

适合没有依据的断言。

- 对方：反正你肯定没认真做。
- 回法：哪儿没做好？别光会说“反正”。
- 更冲：结论张嘴就来，依据一句没有。你这评审挺省事。
- 不适合：对方已经列出具体错误，不能假装对方没证据。

## 用反讽暴露循环

适合怎么回答都被判错的规则。

- 对方：不解释就是默认，解释就是狡辩。
- 回法：答什么都算错，那你还问个什么劲？
- 不适合：对方只是要求简短回答，不一定是在封死所有解释。

## 拆掉替人读心

适合把未经证实的动机当事实。

- 对方：你帮这个忙就是想让人欠你人情。
- 回法：你连我的算盘都替我打好了，证据准备替我补吗？
- 不适合：用户已承认为了交换利益，不能替用户否认已知事实。

## 承认一点，拒绝扩大

适合用户有具体失误，却被推导成整个人都不行。

- 对方：一次顺序弄错，就说明你做事从来不可靠。
- 回法：这次顺序我会改。“从来不可靠”这顶帽子，你留着。
- 重点：真认具体错误，别用道歉开头藏一个全面甩锅。

## 把身份换回观点

适合用资历代替论证。尊重实际经验，不把经验都嘲讽成无用。

- 对方：我见得比你多，这件事不用解释。
- 回法：做得久，连个理由都说不出来？
- 不适合：对方正在说明专业限制或真实责任边界，需回应实质内容。

## 到点收尾

适合已澄清、对方只重复标签的情况。

- 回法：问题已经回答。你想继续重复标签，我不陪。
- 重点：给一条能结束本轮的回复，不设计连续追击，不保证对方会停止。

## 把弱句改成有力句

| 弱在哪里 | 弱句 | 改法 |
| --- | --- | --- |
| 太像客服 | 希望您能够理性客观地看待本次争议。 | 哪儿有问题？挑一处说。 |
| 空标签 | 典，太典了。 | 你把回答都提前判错了，还问什么？ |
| 乱猜心理 | 你就是嫉妒我，比不过才这样。 | 说的是我的方案，你到现在没指出哪一步不行。 |
| 连发追问 | 你懂吗？你会吗？你有什么资格？ | 有依据就说，资格不能替你回答问题。 |
| 用亲属替代内容 | 贬损无关家属。 | 你自己的观点，自己拿依据撑住。 |

## 让分析留在脑子里

| 脑子里判断什么 | 嘴上怎么说 |
| --- | --- |
| 对方未阅读内容就给出否定结论 | 教程没打开，嘴先启动了。 |
| 对方把是否接受解释都当成自己正确的证据 | 怎么答都算你赢，还装什么提问？ |
| 对方未参与工作却声称自己是主要贡献者 | 干活查无此人，领功第一个到。 |
| 对方给自己和别人设置不同的回复时限 | 你那边按天算，到我这儿改秒表了？ |
| 对方从一次具体失误扩大到全盘否定 | 一处错你都嫌少，还得替我编几项？ |

这些句子只在对应事实成立时使用。不要为了套一句好听的回怼，替输入补出“没看”“没参与”“双标”。
