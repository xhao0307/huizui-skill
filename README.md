# 回嘴 · Huizui

**当场没接住的那句话，现在给你五种回法。**

一个中文回怼 Agent Skill。根据公开贴吧讨论片段与幽默精选整理接话机制，帮助你回应恶意挖苦、无根据指控和双重标准。一次给出不同风格，自己选用。

## 看看效果

以下场景与台词均为虚构。

> 背景：对方评论一篇游戏教程。
>
> 对方：一行没看，这玩意肯定没用。

| 风格 | 回复 |
| --- | --- |
| 冷脸直怼 | 没看就说没用，你这评价够省事。 |
| 贴吧阴阳 | 教程没打开，嘴先启动了。 |
| 精准拆招 | 你连内容都没看，评的是哪一段？ |
| 更冲一点 | 屁都没看就开喷，挺把自己当回事。 |
| 一句收尾 | 看完再来，别空评。 |

五种回法分别侧重直怼、讽刺、追问、挖苦和收尾，使用者自己选。

## 怎么用

把对方的话、必要的前后文和使用场景交给模型。请先移除可识别信息。

```text
用 $huizui 帮我回这句：
对方：“你的解释我不听，反正你就是故意的。”
背景：我们正在讨论一次临时改期，对方没有指出具体依据。
场景：普通聊天。
要求：一次给多种回法，不带脏字。
```

默认给出：**冷脸直怼 / 贴吧阴阳 / 精准拆招 / 更冲一点 / 一句收尾**。

也可以说：

- “只要三条，越短越好。”
- “阴阳一点，但不要提家人。”
- “这是工作群，锋利一点，别像投诉模板。”
- “我刚才确实说错了，帮我认这个错，但别接受对方对我的整个人下定义。”

更多效果见 [虚构示例](skills/huizui/references/examples.md)。

## 为什么不只写一句“模仿贴吧老哥”

技能里加入了 [7 张机制卡](skills/huizui/references/tieba-patterns.md) 和 [14 张对照案例卡](skills/huizui/references/casebook.md)。生成前先找原话里的词、动作或记录，再选接法；每张卡都说明关键事实，以及事实变了之后为什么不能继续套用。

例如，下列台词均为原创虚构：

| 背景 | 接法 |
| --- | --- |
| 对方连续重复指责，却嫌别人复读 | 复读键一直在你手里，你喊我松手？ |
| 自己提出投票，结果不合意就说不算 | 你要的是投票，还是大家替你点确认？ |
| 无依据指控抄袭，还让被指控者自己找证据 | 指控你张嘴，证据还得我给你代工？ |

首轮研究查看了 4 个公开讨论页面的可见片段，并从一份含 1,361 个记录的二手年度精选整理中定向筛阅了 97 个候选记录，其中 13 个用于结构对照。**不是读完全部帖子，也不是训练了一个模型。** 范围、取舍和来源限制见 [研究记录](docs/research/2026-11-26-corpus-study.md)。

这是材料启发的上下文与案例增强，尚未通过独立盲测证明优于同模型原生提示词。[迁移试写](evals/2026-11-26-transfer-review.md) 是作者自检；[三组比较方案](evals/ab-protocol.md) 尚待执行。

## 安装

技能目录是 [`skills/huizui`](skills/huizui)，入口为 `SKILL.md`，附带机制卡、对照案例、表达手法和示例。请安装整个目录，单独复制入口会丢失参考材料。没有运行脚本或 API 密钥依赖。

**Codex：** 将整个 `skills/huizui` 文件夹复制到 `~/.codex/skills/`，保持目录名为 `huizui`。已有同名技能时先比较内容。让客户端重新发现技能后，用 `$huizui` 调用。

**其他支持 Agent Skills 的客户端：** 按该客户端的安装方式导入整个 `huizui` 文件夹。安装位置与调用语法以客户端为准；本仓库尚未完成多客户端实测。

## 设计取舍

- **一次多选：** 直接交付不同策略的成稿，不先追问用户选哪档火力。
- **先分清事实：** 不混淆多人发言，不把普通批评判成恶意，不替用户捏造证据。
- **保留锋芒：** 允许挖苦、反问、冷脸回击，回应具体言行。
- **草稿由人决定：** 不自动发消息，也不组织追着别人骂。
- **示例全部虚构：** 不收集真实聊天作为训练集，不把真实人物做成攻击对象库。

这是一套提示词与参考材料，实际效果取决于模型及上下文，不保证让对方服气。技能本身没有采集、保存聊天或上传数据的脚本；模型与客户端如何处理输入，由其自身机制决定。
